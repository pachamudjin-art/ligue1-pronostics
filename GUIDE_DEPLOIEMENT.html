⚽ Guide de déploiement

L1 Pronostics — Sans ligne de commande, depuis votre navigateur

⏱ Temps estimé : 15 minutes — Aucune installation requise sur votre PC. Tout se fait depuis le navigateur. L'hébergement est gratuit sur Railway.

Étape 1 — Créer un compte GitHub

1

GitHub stockera votre code en ligne

  1. Allez sur github.com
  2. Cliquez Sign up et créez un compte (gratuit)
  3. Vérifiez votre email
Si vous avez déjà un compte GitHub, passez à l'étape 2.

Étape 2 — Créer un dépôt GitHub

2

Créer le dépôt qui contiendra le code

  1. Une fois connecté à GitHub, cliquez le + en haut à droite → New repository
  2. Nom du dépôt : ligue1-pronostics
  3. Laissez tout le reste par défaut, cliquez Create repository

Étape 3 — Uploader le code

3

Envoyer les fichiers sur GitHub depuis le navigateur

  1. Dans votre nouveau dépôt vide, cliquez uploading an existing file (lien bleu au centre)
  2. Décompressez d'abord l'archive ligue1-pronostics.zip sur votre bureau
  3. Ouvrez le dossier décompressé. Vous devez voir : backend/, frontend/, requirements.txt, Procfile, README.md
  4. Sélectionnez tous ces fichiers et dossiers et glissez-les dans la zone d'upload GitHub
  5. En bas, cliquez Commit changes
⚠️ Attention : uploadez le contenu du dossier (pas le dossier lui-même). Votre dépôt doit voir backend/ à la racine, pas ligue1-pronostics/backend/.

Étape 4 — Créer un compte Railway

4

Railway hébergera votre application

  1. Allez sur railway.app
  2. Cliquez Login → Login with GitHub
  3. Autorisez Railway à accéder à votre GitHub
Railway propose un plan gratuit (500h/mois, largement suffisant pour 9 joueurs).

Étape 5 — Déployer sur Railway

5

Connecter votre dépôt GitHub à Railway

  1. Dans Railway, cliquez New Project
  2. Choisissez Deploy from GitHub repo
  3. Sélectionnez votre dépôt ligue1-pronostics
  4. Railway détecte automatiquement le Procfile et lance le déploiement
  5. Attendez 1-2 minutes que le déploiement se termine (barre verte = ok)

Étape 6 — Configurer les variables d'environnement

6

Ajouter les variables secrètes

  1. Dans votre projet Railway, cliquez sur votre service → onglet Variables
  2. Ajoutez ces deux variables en cliquant + New Variable :
VariableValeur
SECRET_KEY Une phrase longue au hasard, ex : football2025ligue1pronostics
API_FOOTBALL_KEY Votre clé API-Football (optionnel — voir ci-dessous)
Sans API_FOOTBALL_KEY, l'import automatique du calendrier sera désactivé. Vous pourrez saisir les matchs manuellement depuis l'interface Admin.

Étape 7 — Récupérer l'URL de votre site

7

Obtenir le lien à partager à vos amis

  1. Dans Railway, onglet Settings → section Domains
  2. Cliquez Generate Domain
  3. Vous obtenez une URL du type ligue1-pronostics-production.up.railway.app
  4. Partagez cette URL avec les 9 participants !
🎉 Votre site est en ligne. La base de données se crée automatiquement au premier accès.

Optionnel — Clé API-Football (calendrier automatique)

Importer le calendrier automatiquement

  1. Allez sur api-football.com → Register
  2. Créez un compte gratuit (100 requêtes/jour)
  3. Dans votre dashboard, copiez votre API Key
  4. Collez-la dans Railway comme variable API_FOOTBALL_KEY
  5. Dans votre site, allez Admin → Journée X → Importer depuis l'API
Sans cette clé, saisissez simplement les matchs à la main depuis l'Admin. C'est rapide (9 matchs par journée).

En cas de problème

Vérifications rapides

  • Site inaccessible : vérifiez que le déploiement Railway est vert (pas rouge)
  • Erreur 500 : dans Railway → onglet Deployments → cliquez le dernier déploiement → View Logs
  • Import API échoue : vérifiez que API_FOOTBALL_KEY est bien définie dans Railway Variables
  • Matchs non verrouillés : les horaires sont en UTC. Un match à 21h en France = 19h00 UTC en hiver, 20h00 UTC en été
